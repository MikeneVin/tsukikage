# 月影 TSUKIKAGE — 달그림자의 검

**▶ 플레이: https://mikenevin.github.io/tsukikage/**

명조풍 셀 셰이딩 + 세키로식 체간/튕겨내기 전투의 3인칭 액션 게임. 브라우저에서 바로 실행됩니다(설치 없음).
모델·텍스처·효과음·음악 모두 실행 중에 절차 생성되며 외부 에셋은 없습니다.

- 권장: 데스크톱 Chrome / Edge, 키보드 + 마우스, 하드웨어 가속(WebGL2) 켜짐
- 로딩이 끝나면 아무 키나 눌러 시작 → 화면을 클릭하면 마우스 시점이 활성화됩니다

## 조작

| 키 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| 좌클릭 | 공격 · 체간이 무너진 적에게 인살 |
| 우클릭 | 가드 · 공격 직전에 누르면 튕겨내기 |
| Shift | 회피 (길게 = 질주) · 찌르기(危)에 앞으로 = 간파 |
| Space | 점프 · 아래 쓸기(危)를 뛰어넘어 밟기 |
| E | 상호작용 · 초록 표식에 갈고리 |
| C | 웅크리기(풀숲 은신) |
| Tab / 휠 클릭 | 록온 |
| F / G / X | 전투기술 / 선풍 / 수리검 |
| R | 회복 표주박 |
| M | 지도 |
| P / Esc | 일시정지 |
| Space 길게 | 컷신 건너뛰기 |

이 저장소에는 빌드 결과물만 있습니다.
